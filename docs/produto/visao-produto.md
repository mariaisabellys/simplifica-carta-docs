# Visao do Produto

## Produto

O Simplifica Carta e um manual web informativo e interativo para servidores publicos responsaveis pelo levantamento, organizacao e preparacao das informacoes necessarias para a Carta de Servicos.

## Problema

Servidores precisam transformar informacoes dispersas sobre servicos publicos em dados claros, completos e padronizados para cadastro no Paraiba Digital. Esse processo pode gerar duvidas sobre o que caracteriza um servico publico, quais informacoes sao obrigatorias, como escrever em linguagem simples e como preencher a plataforma oficial.

## Objetivo

Orientar o usuario em um fluxo didatico que ajude a:

- entender o que e a Carta de Servicos;
- identificar se uma atividade caracteriza servico publico;
- reunir as informacoes necessarias;
- preencher uma estrutura de Carta de Servicos;
- revisar obrigatoriedade e linguagem simples;
- visualizar uma previa em HTML;
- exportar dados em CSV;
- copiar informacoes para cadastro manual no Paraiba Digital;
- solicitar ajuda quando necessario.

## Publico-alvo

Servidores publicos estaduais que atuam no levantamento, organizacao ou cadastro de informacoes de servicos publicos.

## Proposta de valor

Reduzir erros, padronizar informacoes, orientar a escrita em linguagem simples e facilitar a preparacao dos dados antes do cadastro oficial.

## Limite do produto

O Simplifica Carta nao substitui o Paraiba Digital, nao realiza publicacao automatica, nao autentica usuarios no MVP e nao salva rascunhos permanentes da Carta de Servicos.
