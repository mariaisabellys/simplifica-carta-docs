# MVP

## Funcionalidades incluidas

- Pagina inicial com apresentacao do Manual Simplifica Carta.
- Navegacao principal entre secoes essenciais.
- Fluxo guiado por etapas.
- Pagina "O que e a Carta de Servicos".
- Diagnostico interativo para identificacao de servico publico.
- Tela de resultado do diagnostico.
- Etapa de organizacao das informacoes necessarias.
- Formulario de elaboracao da Carta de Servicos dividido em partes.
- Validacao de campos obrigatorios.
- Sugestoes de melhoria baseadas em linguagem simples.
- Pre-visualizacao em HTML das informacoes preenchidas.
- Armazenamento temporario durante a sessao.
- Disponibilizacao das informacoes para copia no tutorial do Paraiba Digital.
- Exportacao das informacoes em CSV.
- Tutorial de cadastro no Paraiba Digital.
- Fluxo "Preciso de ajuda".
- Solicitacao basica de atendimento agendado.
- Suporte por e-mail.
- Interface responsiva para computadores, tablets e smartphones.

## Fora do MVP

- Area completa de materiais de apoio.
- Busca avancada de conteudo.
- Glossario completo.
- Painel administrativo para edicao de conteudo.
- Autenticacao de usuarios.
- Salvamento permanente de rascunhos.
- Publicacao automatica no Paraiba Digital.
- Integracao direta com sistemas externos.
- Gestao completa de agenda integrada a calendario institucional.

## Definicao de pronto do MVP

O MVP sera considerado concluido quando o usuario conseguir percorrer o fluxo principal, identificar se uma atividade caracteriza servico publico, preencher as informacoes da Carta, receber validacoes, visualizar previa HTML, exportar CSV, acessar o tutorial do Paraiba Digital, copiar as informacoes preenchidas e solicitar atendimento agendado.
