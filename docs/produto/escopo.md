# Escopo

## Dentro do escopo

O produto cobre a jornada de preparacao da Carta de Servicos, desde a compreensao inicial ate a organizacao dos dados para cadastro manual no Paraiba Digital.

O MVP tambem cobre um fluxo minimo de atendimento agendado e suporte por e-mail.

## Fora do escopo

Nao fazem parte do MVP:

- publicacao automatica de servicos;
- integracao direta com o Paraiba Digital;
- area administrativa completa;
- login;
- historico de Cartas;
- rascunhos permanentes;
- busca avancada;
- gestao institucional completa de agenda.

## Criterio para novas ideias

Uma nova ideia so entra no MVP se for essencial para o fluxo principal ou para o atendimento minimo. Caso contrario, deve ser registrada como evolucao futura.
