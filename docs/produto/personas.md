# Personas

## Servidor responsavel pelo levantamento

Precisa entender se uma atividade e um servico publico, reunir informacoes corretas e evitar retrabalho.

Necessidades principais:

- orientacao passo a passo;
- exemplos claros;
- validacao de informacoes obrigatorias;
- linguagem simples;
- possibilidade de pedir ajuda.

## Servidor responsavel pelo cadastro

Precisa copiar informacoes organizadas para o Paraiba Digital.

Necessidades principais:

- dados estruturados;
- visualizacao previa;
- exportacao CSV;
- campos prontos para copia;
- tutorial de cadastro.

## Equipe GESED

Precisa orientar orgaos, padronizar informacoes e acompanhar solicitacoes basicas de suporte.

Necessidades principais:

- conteudo facil de manter no codigo;
- fluxo didatico;
- solicitacoes de atendimento registradas;
- notificacoes por e-mail.
