# Ajustes de implementação

Documento colaborativo para registrar alterações identificadas durante a revisão
das páginas implementadas. Os pontos podem ser adicionados aos poucos e serão
aplicados em uma rodada consolidada ao final da implementação das features.

## Como registrar um ajuste

Para cada alteração, use o modelo abaixo. Escreva uma observação por item,
mesmo que a alteração envolva mais de um arquivo.

```md
### AJ-000 — Título curto do ajuste

- Status: `pendente`
- Feature/página: `002-home-e-navegacao`
- Rota: `/`
- Tipo: `visual` | `conteúdo` | `comportamento` | `acessibilidade` | `responsividade`
- Prioridade: `alta` | `média` | `baixa`
- Elemento afetado: nome do componente, seção ou campo
- Problema observado: o que está diferente ou precisa melhorar
- Alteração desejada: como deve ficar
- Comportamento esperado: o que deve acontecer em cada estado ou interação
- Viewport/estado: desktop, tablet, mobile, vazio, preenchido, erro etc.
- Referência visual: caminho da imagem local ou descrição da imagem anexada
- Critério de aceite: como confirmar que o ajuste foi concluído
- Observações: contexto adicional, se necessário
```

## Imagens de referência

Quando uma imagem for enviada, salve-a em uma pasta de referências antes de
aplicar o ajuste. Use nomes que relacionem a imagem ao código do item:

```text
docs/referencias/ajustes/
├── AJ-000-descricao-curta-desktop.png
├── AJ-000-descricao-curta-mobile.png
└── AJ-000-anotacoes.md
```

No item, informe:

- o caminho relativo da imagem;
- o viewport usado;
- o estado representado;
- se a imagem é referência visual normativa ou apenas inspiração;
- áreas destacadas e o que deve ser alterado.

Não incluir na imagem dados pessoais, credenciais ou conteúdo restrito.
